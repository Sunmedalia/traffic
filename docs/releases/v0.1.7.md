# traffic v0.1.7

本版让中文终端界面与 Web 对齐，加快本地分析结果的查询，并修复 Linux 采集在证据页缓存和 tmpfs 会话目录上的停采问题。升级时请配对使用同版本的 `traffic` 采集器和 `traffic-console` 分析器。

## 终端界面

终端界面的页面、筛选条件和操作逻辑与 Web 对齐，两边读取同一份分析结果。 [PR #24 与截图](https://github.com/Sunmedalia/traffic/pull/24)

- **概览**：显示累计请求、告警命中、网络包和三类丢弃六项指标，下方是请求与告警时间线，以及命中规则、来源地址、告警级别、响应状态、最近告警和采集状态。时间线纵轴标出每格峰值，横轴按整点刻度标注；`←→` 移动，`Shift+←→` 选择时间段，`Enter` 查看这段时间的请求。
- **请求与筛选**：列顺序与 Web 相同，列表上方显示筛选后的时间线，`t` 在时间线上选择时间范围。`/` 筛选面板补齐 Web 的全部条件：URL 解码后匹配、响应状态、方法、隐藏静态资源、排除词、包含参数和具体状态码。
- **详情**：请求与响应默认在同一页左右并排，`L` 切换左右、上下和单独三种排版，宽度不足 90 列时自动上下排列；`<` / `>` 调整列表与详情的宽度，最宽为详情全屏。新增「参数」标签，按查询参数、表单参数和 Cookie 列出原文，`Enter` 在解码工具中打开所选参数。响应正文也提供解压视图，JSON 正文默认格式化。
- **解码工具**：`d` 打开，支持 URL、Base64、Hex、HTML 实体、Unicode 转义、JWT 和 Gzip / Deflate，可以连续解码、撤销和查看十六进制。
- **分析面板**：`A` 用内置规则或 `--rules-dir` 中的规则文件重新分析当前会话，可以查看进度、停止任务和查看最近任务。`traffic-console view` 现在接受 `--rules-dir`。
- **其他**：会话列表按日期分组，只有一个会话时直接打开；`z` 切换本地时间与 UTC；已结束的会话不再每秒自动刷新，`r` 立即刷新。

操作变化：详情中 `j` / `k` 切换上一条或下一条记录，`↑` / `↓` 滚动；告警页默认显示逐条列表，`v` 切换聚合视图。

## 本地分析

- 分析引擎升级到 v5。列表、筛选和统计读取独立的 `entries` 表，不再解析含正文的 JSON。2,000 条事务、请求和响应正文各 16 KiB 时，按方法筛选计数从 54 ms 降到 0.17 ms，状态码分布从 145 ms 降到 0.32 ms。大会话的 Web 概览可以完整显示状态码分布。
- v1 `index.sqlite` 会话和 v4 及更早的分析结果无需重新分析即可查看，重新执行 `analyze` 后改用新表查询。v5 结果仍保留旧版 console 可读的数据。
- 分析库支持多个只读连接，Web 的并发请求不再排队。
- 分析库直接在会话目录内构建为隐藏的 `.analysis-build-*.sqlite`，完成后改名发布，不再写入系统临时目录（常见为内存 tmpfs）。异常退出遗留的构建文件会在之后一次成功发布时清理。 [PR #22](https://github.com/Sunmedalia/traffic/pull/22)
- 会话所在磁盘写满时，`analyze` 报告磁盘空间不足，不再只显示 `cannot commit - no transaction is active`。证据 ZIP 成员使用导出时间作为时间戳。

## Linux 采集

- PCAP 分段和 `tls/stream.jsonl` 每写入 8 MiB 回写并释放页缓存，页缓存不再挤满采集器内存限制（默认 256 MiB），避免默认 strict 策略下因 `raw-tls/evidence_queue_overflow` 停采。
- 会话目录位于 tmpfs 或 ramfs、存在内存 cgroup 限制，且 `--disk-limit-mib` 超过内存预算一半时，采集器在开始抓包前拒绝采集，状态记为 `failed` 并给出处理方法。这类证据会计入内存限制，原先约写到 250 MiB 时采集器会被 OOM 终止。非 root 或没有 cgroup 时行为不变。 [PR #23](https://github.com/Sunmedalia/traffic/pull/23)

## 验证范围

- Debian 13、2 vCPU：采集、分析、导出全流程 200 个事务；ext4 上约 11 万 req/s 采集到 2 GiB 磁盘预算后正常停止，`queue_dropped=0`；tmpfs 会话目录在 `--disk-limit-mib 128` 时以约 10 万 req/s 运行，按磁盘预算停止。
- 修复 OpenSSL 预加载队列测试中的两处时序竞态，该测试原先偶发失败，与预加载库本身无关。 [PR #25](https://github.com/Sunmedalia/traffic/pull/25)
- 终端界面在 Linux 上通过单元测试和多种终端尺寸的布局测试，尚未在 Windows 终端中逐项核对。

## 下载与校验

Ubuntu 和 CentOS 7+ 提供 amd64、arm64 包，Windows 提供 amd64 包。每个平台分别提供采集器和分析器。用本次发布的 `SHA256SUMS` 校验下载文件，完整解压并保留随包依赖。停采后，在分析机运行 `traffic-console analyze --session DIR`。
