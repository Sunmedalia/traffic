# traffic v0.1.5

本版更新 Windows 采集、离线 PCAP 回放和 Linux eCapture 队列。升级时请配对使用同版本的 `traffic` 采集器和 `traffic-console` 分析器。

## 采集与回放

- Windows 修正 WinDivert 批量接收的时间戳处理，改进 IIS 接收恢复和 TLS 覆盖状态。 [PR #15](https://github.com/Sunmedalia/traffic/pull/15)
- 离线 PCAP 回放在下游繁忙时等待队列容量，并在慢响应场景保留事务。改进 HTTP/1 请求与响应配对、HTTP/2 流的时间戳和生命周期，以及证据包的报文时间窗口。 [PR #16](https://github.com/Sunmedalia/traffic/pull/16) [PR #17](https://github.com/Sunmedalia/traffic/pull/17)
- 增加实时 libpcap 接收缓冲区配置，保留部分非规范 HTTP 请求的原始字节。Linux eCapture 使用每次采集独立的私有事件队列，采集器异常退出后由独立进程清理队列。 [PR #18](https://github.com/Sunmedalia/traffic/pull/18) [PR #19](https://github.com/Sunmedalia/traffic/pull/19)

## 已知限制

- 非规范 HTTP/1 消息的 `Content-Length` 存在歧义时，后续响应可能与错误的请求配对。
- 某些分块传输消息的原始证据可能超过配置的正文保存上限。

## 下载与校验

Ubuntu 和 CentOS 7+ 提供 amd64、arm64，Windows 提供 amd64。每个平台分别提供采集器和分析器。用同版本 `SHA256SUMS` 校验下载文件，完整解压并保留随包依赖。
