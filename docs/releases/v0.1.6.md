# traffic v0.1.6

本版更新 Web 请求排查和 Windows nginx HTTPS 明文采集。升级时请配对使用同版本的 `traffic` 采集器和 `traffic-console` 分析器。

## Web 控制台

- 分析可在打开会话后启动，支持选择规则、停止分析和查看该会话的近期任务。会话与会话规则放在可折叠的侧边栏，概览、请求和告警位于会话顶栏。
- 请求详情默认显示报文。宽屏在「请求/响应」视图并排展示两侧报文，窄屏使用独立标签切换。方法、状态、URL、时间和来源等字段可通过「展开记录信息」查看。导出证据位于复制报文按钮旁。 [PR #20 与截图](https://github.com/Sunmedalia/traffic/pull/20)

## Windows nginx

- 新增 nginx.org Windows x86 1.27.4 和 iliweii/nginx-rtmp-win64 Windows x64 1.28.1 的静态 OpenSSL profile，继续支持 nginx.org Windows x86 1.28.0。其他无导出符号的静态构建需要匹配的自定义 profile。
- nginx 明文探针不可用时记录附加缺口。worker 退出时转发 helper 已收到的尾部事件，报告已知队列丢弃，并记录无法确认排空的退出。
- IIS 的 `--require-plaintext` 只接受已经进入证据队列的 IIS 请求明文。 [PR #21](https://github.com/Sunmedalia/traffic/pull/21)

## 验证范围

Windows 11 ARM64 虚拟机已验证 nginx 明文探针与离线还原，覆盖 TLS 1.2 和 TLS 1.3。该环境拒绝加载随包 WinDivert 驱动，Windows 10 x64 的 WinDivert 全链路尚未复验。 [验证记录](https://github.com/Sunmedalia/traffic/pull/21)

## 下载与校验

Ubuntu 和 CentOS 7+ 提供 amd64、arm64 包，Windows 提供 amd64 包。每个平台分别提供采集器和分析器。用本次发布的 `SHA256SUMS` 校验下载文件，完整解压并保留随包依赖。
