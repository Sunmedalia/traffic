# traffic v0.1.8

本版为中文终端界面加入鼠标操作，并修复内置命令注入规则 CMD-001 对普通参数的误报。采集器没有功能变化。升级时请配对使用同版本的 `traffic` 采集器和 `traffic-console` 分析器。

## 终端界面：鼠标操作

终端界面支持点击、滚轮、拖动和右键，点击的效果与 Web 相同。 [PR #26](https://github.com/Sunmedalia/traffic/pull/26) · [PR #27](https://github.com/Sunmedalia/traffic/pull/27) · [PR #28](https://github.com/Sunmedalia/traffic/pull/28)

- **点击**：可以点击以下内容：
  - 标签栏、列表行、详情标签、告警视图切换与聚合行、参数行；
  - 解码来源、解码步骤和解码方式；
  - 底部和页面中的按键提示，点一下等于按下对应的键。

  点「筛选」打开筛选面板，点某个筛选条件只去掉这一条。筛选、导出和分析面板提供可点击的选项和按钮。会话列表点击即可打开会话。
- **请求列表**：
  - 单击一行，在右侧打开详情；再点同一行收起详情（快速双击不会收起）。
  - 拖动列表与详情之间的分隔线可以调整宽度，列表至少 30 列、详情至少 50 列；比例在调整终端大小和切换会话后保留，双击分隔线恢复各占一半。
  - 一页放不下时，右侧显示可拖动的滚动条。
  - 页脚的 `‹ 上一页` / `下一页 ›` 在打开详情时也能翻页，右侧详情保持不变。
- **概览**：单击某一行，在提示栏显示摘要，例如规则的级别和命中数、来源的请求数与告警数、状态占比、最近告警的时间和 URL；再点一次同一行才进入对应列表，避免误点离开概览。
- **时间线**：列表上方的时间线拖动后直接按这段时间筛选。概览的时间线拖动或单击只选中时间段，再点一次选中处查看这段时间的请求。
- **滚轮与右键**：滚轮滚动列表、详情和健康页；分栏时滚动左侧列表不会换掉右侧详情。右键返回上一层，等同 `Esc`。
- **关闭鼠标**：按 `M` 关闭或开启鼠标操作。鼠标开启时，多数终端需要按住 `Shift` 才能选取文字。
- **键盘**：列表的滚动位置与光标分开保存，向上移动光标时不再把光标固定在最底行。

## 检测规则

- CMD-001（命令注入）原先会把与命令同名的普通参数当成注入，例如 `/search?q=手机&cat=3`、`/orders?id=42` 或表单 `user=a&id=7`，并报为高危。
- 现在要求分隔符后的命令再跟空白、结尾或 shell 元字符；`;cat /etc/passwd`、`|id`、`&&whoami`、`$(id)` 等真实注入照常命中。
- 规则版本升为 2。一个测试会话包含大量 `&cat=3` 搜索请求，修复前 CMD-001 命中 382 条，修复后为 11 条，全部是真实攻击。
- 已有分析结果不会自动更新：用本版 `traffic-console analyze`，或在终端 / Web 的分析面板重新分析，即可去掉旧的误报。

## 验证范围

- 终端界面新增单元测试，覆盖以下内容：
  - 点击区域定位；
  - 按键提示解析；
  - 点击、滚轮、滚动条和分隔线拖动；
  - 时间线选择与概览的「再点一次」；
  - 打开详情时翻页。
- 用合成 PCAP 导入并分析了 3 个会话，共约 1.9 万条请求。在真实终端程序上输入 SGR 鼠标序列，逐项核对了上述操作。
- 鼠标操作尚未在 Windows 终端中逐项核对。

## 下载与校验

Ubuntu 和 CentOS 7+ 提供 amd64、arm64 包，Windows 提供 amd64 包。每个平台分别提供采集器和分析器。用本次发布的 `SHA256SUMS` 校验下载文件，完整解压并保留随包依赖。停采后，在分析机运行 `traffic-console analyze --session DIR`。
